n8n for agencies

Your n8n workflow stopped three days ago. Nothing told you.

An error is easy to catch. A workflow that quietly stops running is not. One agency owner reported losing a $2,500 a month client after a three-day silent failure.

Status: the free open-source kit exists and works today. The hosted version described below is not built yet. Nothing here can be bought today.

What the free kit does today

  • Silent-failure check. Reads each workflow's schedule, compares it with the n8n API, and flags workflows that stopped running or keep failing. Exits non-zero so it runs from cron.
  • Several clients, no stored secrets. One config file lists clients by name. URLs and API keys stay in environment variables on your machine.
  • Five more tools in the same repo. Dependency graph, client reports, handover docs, a workflow linter and spend and loop caps for AI agents.

What the hosted version will add

  • Multi-client dashboard. Every client instance in one view, without running scripts yourself.
  • Alerts. A message when a workflow stalls or starts failing, from a service that is not running on the same server as n8n.
  • White-label monthly client report. A report you can send under your own agency name.
